FC ARENA ULTIMATE TEAM — yangilangan prototip

NIMALAR QO‘SHILDI:
- Ultimate Team uslubidagi bosh sahifa.
- Afsonaviy va zamonaviy futbolchi kartalari.
- Kartada reyting (OVR), pozitsiya (ST, RW, CM...), davlat bayrog‘i va klub belgisi/nomi.
- Pack ochish animatsiyasi va 3 ta tasodifiy karta.
- Kolleksiya va Afsonalar/Yangi yulduzlar filtri.
- 4-3-3 tarkib ekrani va futbolchi almashtirish.
- 3D mashq maydoni va mobil joystick, pas, zarba, almashish tugmalari.

MUHIM CHEKLOVLAR:
- Bu ishlab chiqish prototipi; FC Mobile darajasidagi tayyor mahsulot emas.
- Kartalardagi reytinglar o‘yin uchun demo qiymatlar, rasmiy EA reytinglari emas.
- Hozircha futbolchi portretlari o‘rnida emoji/siluet ishlatilgan. Haqiqiy rasmlar va klub logotiplari uchun litsenziyali assetlar kerak.
- Pack animatsiyasi va kartalar lokal demo. Onlayn inventar, serverda pack natijasi, akkaunt sinxronlash va xavfsiz multiplayer backend hali ulanmagan.
- Google sign-in tugmasi hozir tushuntiruvchi demo. Firebase loyihasi, OAuth sozlamalari va ruxsat etilgan domenlar kiritilgandan keyin haqiqiy Google login ulash mumkin.
- 3D match prototipi hozir offline mashq; haqiqiy online PvP uchun server-authoritative game state, matchmaking, lag compensation va anti-cheat kerak.
- Bu ZIP ichida tayyor APK yo‘q.

ISHGA TUSHIRISH:
1. Node.js LTS o‘rnating.
2. Loyiha papkasida terminal oching.
3. npm install
4. npm start
5. http://localhost:3000 manzilini oching.
Internet kerak: Three.js CDN orqali yuklanadi.

ANDROID:
Bu web prototip. Android APK uchun Capacitor + Android Studio/SDK orqali build qilish kerak. Hosting va Google OAuth domeni alohida sozlanadi.

Keyingi ishlab chiqish:
1. Firebase Auth + Firestore profil/inventar.
2. Real-time multiplayer server.
3. Litsenziyali futbolchi rasmlari, klub logotiplari va animatsiyalar.
4. To‘liq 3D o‘yin mexanikasi, darvozabon, gol, taktikalar va AI.
